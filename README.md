## Kesimpulan

Pada tugas 4, dipelajari penggunaan struktur data seperti list, tuple, set, dan dictionary yang menjadi fondasi penting dalam pengelolaan data. Pada tugas 5, dipelajari pembuatan function dan class  untuk membangun program yang lebih terstruktur dengan pendekatan pemrograman berorientasi objek. Selanjutnya, pada tugas 6, Python digunakan untuk pengolahan data dengan bantuan NumPy dan pandas.

Secara keseluruhan, ketiga tugas ini menunjukkan  pemahaman dari konsep dasar Python, penerapan function dan OOP, hingga pengolahan data . Dari proses tersebut, dapat dipahami bahwa Python  cocok digunakan baik untuk pembelajaran dasar maupun untuk pengembangan program yang lebih kompleks.
